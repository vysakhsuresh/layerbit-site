About Layerbit

Layerbit is a small independent studio in the United Arab Emirates that builds browser-based developer utilities and takes on custom engineering work. Every tool on this site is free, needs no account, and — with one clearly marked exception — does all of its work inside your own browser.

How Layerbit started

Layerbit began as a personal collection of small scripts built to solve recurring, everyday frustrations in a developer's workflow — decoding a stray JWT from a log file, reformatting a query someone had written as one 400-character line, converting a CSV export without opening a spreadsheet and watching it mangle the leading zeros.

Those were command-line snippets living in a dotfiles repository, which meant they were useless on a colleague's machine, on a phone, or on a locked-down corporate laptop. Rebuilding them as browser tools removed all three problems at once. The catch with most online tools, though, is that pasting a token or a production query into someone else's web form means handing it to a server you know nothing about. That single objection is what shaped everything else about how this site is built.

How your data is actually handled

We would rather be specific than reassuring, so here is the precise arrangement:

Local tools. The JSON validator, SQL formatter, JWT decoder, Base64 encoder, CSV and YAML converters, URL encoder, regex tester, text diff, log analyzer, JSON table viewer, HTML escaper, cron generator, QR generator and PINT-AE checker all run entirely as JavaScript in the page you have open. Your input is never transmitted anywhere, because there is no endpoint for it to be transmitted to. You can verify this — open your browser's network tab and watch nothing leave while you work. You can also load a tool, disconnect from the internet, and keep using it.

LayerLink. Screen sharing is the one exception, and it has to be: two browsers cannot find each other without help. LayerLink uses WebRTC, so the video stream itself travels directly between the two participants. A signalling service is used only for the initial handshake — the connection details each browser needs to locate the other — and it never carries video. This tool is badged Cloud API on the homepage so the difference is visible before you click.

Third-party services. This site serves ads and uses analytics, which set cookies, and a notice asks for your consent before that happens. Beyond those, we have deliberately removed tools that depended on external APIs. Three utilities that queried outside services for breach data, URL reputation and IP geolocation were taken down in September 2026: they relied on infrastructure we did not control, could break without warning, and required sending your input to someone else. A tool we cannot make a straight promise about is not a tool we want to offer.

What we build

The toolkit covers four areas, and the guides and tool reference page lists every one of them with a description:

Data conversion and encoding — Base64, CSV ↔ JSON, YAML ↔ JSON, URL encoding and HTML entity escaping. Code formatting and inspection — JSON validation with a collapsible tree view, SQL formatting across dialects, JSON as a table, text diffing, regex testing and log analysis. Security and identity — JWT decoding with local signature verification, and QR generation. Scheduling, collaboration and compliance — visual cron building with next-run previews, LayerLink screen sharing, and a UAE PINT-AE e-invoicing field checker.

Alongside the free tools, Layerbit takes on client engineering work: API automation, ERP development, mobile and web applications, static site delivery and portfolio design. Those pages are linked from the Built for You section of the homepage.

Why we write the guides

A tool that formats your YAML is useful. Understanding why your unquoted Norwegian country code became the boolean false is what stops the bug happening again. So each utility is paired with a written guide covering the specification corners and the failure modes we have actually run into — the cron rule that makes day-of-month and day-of-week an OR rather than an AND, the regular expression shape that turns a validation check into a denial-of-service vector, the difference between decoding a JWT and verifying one.

These are written from working experience and checked against the relevant specifications — RFC 3986 for URLs, RFC 4648 for Base64, RFC 4180 for CSV, RFC 7519 for JWTs. Where a topic carries real-world consequences we say so plainly, and where something depends on a regulator's timetable rather than a standard — as UAE e-invoicing does — we tell you to confirm it with the authority instead of trusting an article.

How this is funded

Layerbit is free and has no paid tier, no upsell and no account system. It is funded by advertising on the site, by the custom engineering work described above, and by the occasional coffee from someone who found a tool useful. We think it is worth stating that openly: ads are why these tools can stay free without a login wall, and knowing who pays for something you use is reasonable information to have.

What that funding does not buy is your data. Because the local tools never transmit what you paste into them, there is nothing for us to collect, sell, or lose in a breach — the architecture makes the promise for us rather than relying on our good intentions.

How the site is built

Layerbit is a static site, which is a deliberate choice rather than a limitation. There is no application server, no database and no session state, so there is very little that can go wrong or be attacked. Pages are composed from shared partials by a small Python build script and served as plain HTML.

Two checks run on every change before it ships: a structural validator that confirms every page's HTML tags balance, that all structured-data blocks parse as valid JSON, and that every inline script is syntactically valid; and an idempotency check that fails the build if any served page has drifted from the source it is generated from. Ordinary, unglamorous engineering hygiene — but it is why a change to one page does not quietly break another.
