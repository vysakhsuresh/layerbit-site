No connection

You are offline

That is fine for most of Layerbit. Every tool runs entirely inside your browser, so any tool page you have opened before is still available from the cache, and it works exactly as it does online.

What still works

  • Any tool page you have visited since installing or first loading the site.
  • Formatting, validating, diffing, hashing, decoding — none of it needs a server.
  • Share links and history, which are stored in this browser only.

What does not

  • Pages you have never opened (they were never cached).
  • LayerLink screen sharing, which needs a connection by nature.
