Tool reference

Every utility in the suite, grouped by what it does. All of them run in your browser; the ones marked as local never send your input anywhere.

Data conversion & encoding

Base64 Encode / Decode

Convert text or file contents to and from Base64 for safe transport through text-only channels such as JSON, email and data URIs. See the Base64 guide for the padding and URL-safety rules.

CSV ↔ JSON Converter

Standards-correct CSV parsing — quoted commas, doubled quotes and embedded newlines all handled — with type inference, plus JSON back to CSV building the header from the union of all keys.

YAML ↔ JSON Converter

Convert in both directions and inspect the real parsed types, which is the fastest way to catch YAML's implicit conversions before they reach a pipeline.

URL Encoder / Decoder

Smart mode preserves URL structure while encoding query values; raw mode does strict component encoding. Includes an editable parameter grid and a batch mode for lists of URLs.

HTML Escape / Unescape

Convert between raw characters and HTML entities in both directions — handy for checking what a template escaped, and for spotting double-escaped output.

Code formatting & inspection

JSON Validator & Formatter

Validate, beautify and minify JSON, with a collapsible tree view alongside the raw text for navigating deeply nested API responses.

Universal SQL Formatter

Reformat queries into a consistent, readable shape across several database dialects, so diffs stay meaningful and reviews focus on logic.

JSON Table Viewer

Turn arrays of objects into a readable table, including records with differing key sets, for scanning large API payloads quickly.

Text Diff Checker

Compare two blocks of text or code side by side with the differences highlighted, for config drift and copy review.

Regex Tester

Live matching with capture-group breakdown and a replacement preview. Pair it with the backtracking guide before shipping a pattern.

Log Analyzer

Highlight errors, warnings and patterns across pasted log output to find the relevant lines faster.

Security & identity

JWT Decoder & Verifier

Split a token into header, payload and signature, and verify HMAC or RSA signatures locally with the Web Crypto API. Start with decoding vs verifying.

QR / Barcode Generator

Generate downloadable QR codes and barcodes for links and text, with structural risk hints on the encoded URL.

Scheduling, collaboration & compliance

Cron Expression Generator

Build a schedule visually, read it back in plain English, and preview the next five run times in UTC. See the cron guide for the OR rule.

LayerLink Screen Sharing

Peer-to-peer browser screen sharing over WebRTC with no installation. Share a link from a desktop browser and view it from anywhere.

UAE PINT-AE Compliance Checker

Check invoice data against the PINT-AE field structure and export PINT-AE style XML. Background in the UAE e-invoicing guide.

All utilities are free and need no account. Open the main dashboard to get started.
